# Booking System — Project Roadmap

## Why am I building this project?

I am building this Booking System as a **practical backend + database engineering project**.

The goal is not just to make a working booking application. I want to use this project as a **real engineering laboratory** where I can apply the database and backend concepts I learn and gradually improve the system.

I will start with a simple Booking System and evolve it step by step instead of building everything at once.

---

## What am I going to build?

The initial system will contain the core entities:

- User
- Hotel
- Room
- Booking

I will start with a basic relational design using **PostgreSQL** and gradually connect it with my Node.js backend.

As I learn more concepts, I will revisit the existing design and improve it where required.

```text
Basic Booking System
        ↓
Database Integration
        ↓
Authentication & Authorization
        ↓
Booking Logic
        ↓
Transactions
        ↓
Concurrency & Double-Booking Prevention
        ↓
Indexes & Query Optimization
        ↓
Advanced Database Concepts
        ↓
Scaling / HLD
```

---

## Why will this project be useful for me?

This project will give me one continuous system where I can connect **theory with practical implementation**.

Instead of learning databases, backend, concurrency, transactions, indexing, and system design as completely separate topics, I will repeatedly apply them to the same real-world problem.

By the end, the project should demonstrate that I can not only write backend code, but also **design, reason about, test, optimize, and scale a database-backed system**.
